# 📱 คู่มือการสร้างไอคอน Smartphone มาตรฐาน 16x16 (Smartphone Icon Master Guide)

คู่มือนี้อธิบายสถาปัตยกรรม, โครงสร้างตารางพิกเซล, กฎการจัดกึ่งกลาง (Centering Rules), แม่แบบสี, และขั้นตอนการทำงานด้วยสคริปต์ Python อัตโนมัติ เพื่อให้ได้ไอคอนที่สวยงาม คมชัด และตรงตามมาตรฐานของโปรเจกต์ 100%

## 1. 📐 มาตรฐานขนาดและรูปแบบไฟล์ (File Standard)

- **ขนาดภาพ**: **16x16 พิกเซล** เท่านั้น (ห้ามใช้ 32x32 หรือขนาดอื่นสำหรับ UI มือถือ)
- **รูปแบบสี**: **PNG 4-bit Indexed Color (Color Type 3)** พร้อมช้างก์ `PLTE` (Palette 7 สี)
- **ไฟล์ต้นแบบมาตรฐาน**: [settings.png](file:///c:/Users/ZirconX/Downloads/server-testing/development_resource_packs/Moblie%20-%20RP/textures/icons_apps/settings.png) (~200 ไบต์ คมชัด ไม่กินแรม โหลดเร็วที่สุดบน Bedrock UI)

## 2. 🎨 โครงสร้าง Palette 7 สี (7-Color Palette Structure)

ไอคอนมือถือทุกรูปใช้พาเลตต์ 7 สีหลักตามลำดับดัชนี (Index 0 ถึง 6):

| Index | บทบาทหน้าที่ | รายละเอียด | ตัวอย่างโค้ดสี |
| :---: | :--- | :--- | :--- |
| **0** | **Outer Frame** | กรอบนอกสีดำทึบล้อมรอบการ์ดทั้งหมด | `#070b13` |
| **1** | **Notch & Shadow Base** | รอยบากมุมบนซ้าย-ขวา และแถบเงาฐานล่าง 3D | สีโทนเข้มของธีม (Dark Shade) |
| **2** | **Main Background** | สีพื้นหลังหลักของการ์ดตามธีมของปุ่ม/แอป | สีธีมสดใส (เช่น เขียว, แดง, ม่วง, ส้ม) |
| **3** | **Main Symbol / White** | สัญลักษณ์หลัก, ขอบสัญลักษณ์, แถบสีขาว | `#ffffff` หรือสีหลักของวัตถุ |
| **4** | **Highlight** | แสงไฮไลต์ด้านบนของสัญลักษณ์ เพิ่มมิติความลึก | สีขาวนวล หรือโทนอ่อนของสัญลักษณ์ |
| **5** | **Under-shadow** | เงาตกกระทบใต้สัญลักษณ์บนการ์ด (3D Extrusion) | สีเงาเข้มจัด (เช่น เงาใต้หัวใจ/จอยเกม) |
| **6** | **Accent Color** | สีลูกเล่นเสริม (เช่น ปุ่มกดสีทอง, ตาตัวละคร, ป้ายราคา) | สีตัด/ประกาย (เช่น `#facc15`, `#38bdf8`) |

## 3. ⚖️ กฎเหล็กการจัดกึ่งกลาง (CRITICAL: Centering & Symmetry Rules)

> [!IMPORTANT]
> **แกนกึ่งกลางภาพ 16x16 อยู่ที่ `x = 7.5` (ระหว่างคอลัมน์ 7 และ 8)**  
> หากรูปเบี้ยวซ้ายหรือขวาเพียง 1 พิกเซล จะเห็นความไม่สมดุลบนหน้าจอมือถือทันที!

### 📌 สูตรตรวจสอบความสมดุลซ้าย-ขวา (Margin Balance Formula):
ให้ `min_x` คือคอลัมน์ซ้ายสุดของสัญลักษณ์ และ `max_x` คือคอลัมน์ขวาสุดของสัญลักษณ์ (ตัดสี 0, 1, 2 ออก):
$$\text{Left Margin} = \text{min\_x} - 1$$
$$\text{Right Margin} = 14 - \text{max\_x}$$
$$\text{Difference} = \text{Left Margin} - \text{Right Margin} \implies \mathbf{ต้องเป็น\ 0\ เสมอ!}$$

- **ถ้าความกว้างสัญลักษณ์ = 10 px**: ต้องอยู่ระหว่าง `x = 3 .. 12` (ขอบซ้าย 2 px, ขอบขวา 2 px)
- **ถ้าความกว้างสัญลักษณ์ = 8 px**: ต้องอยู่ระหว่าง `x = 4 .. 11` (ขอบซ้าย 3 px, ขอบขวา 3 px)
- **ถ้าความกว้างสัญลักษณ์ = 6 px**: ต้องอยู่ระหว่าง `x = 5 .. 10` (ขอบซ้าย 4 px, ขอบขวา 4 px)
- **สูตรสมมาตร (Horizontal Symmetry)**: สำหรับรูปสมมาตร (เช่น หัวใจ, ถังขยะ, จอยเกม, ลูกโลก) ทุกแถว `y` พิกเซลที่ตำแหน่ง `x` จะต้องตรงกับพิกเซลที่ตำแหน่ง `15 - x` (`pixel[x] == pixel[15 - x]`)

## 4. 🖼️ โครงสร้างกรอบการ์ด 16 แถว (Master Template Grid)

## 7. 🧠 ปรัชญาการออกแบบไอคอนระดับพรีเมียม (Smart Icon Design Philosophy)

การออกแบบไอคอนขนาดจิ๋ว 16x16 ให้ออกมา "สวย ฉลาด และพรีเมียม" ต้องยึดหลัก 4 ประการ:

### 7.1 Context-Aware Palette (วิเคราะห์พาเลตต์ทั้งระบบก่อนลงสี)
- **อย่าสุ่มสีเดี่ยวๆ**: ให้เปิดดูรายการแอปทั้งหมดบนหน้า Home ก่อน (เช่น `home.js` มี แอปสโตร์=น้ำเงิน, ตลาด=เขียว, ธนาคาร=ทอง, ทวิตเตอร์=ฟ้า, ตั้งค่า=ม่วง)
- **สร้างจุดเด่น (Focal Point)**: เลือกสีพื้นหลังของการ์ดในเฉดที่ยังไม่มีบนหน้าจอ เช่น แอปข่าวสาร (`news.png`) เลือกใช้ **Rose Red (`#e11d48`)** สไตล์ Apple News / BBC ทำให้ไอคอนสะดุดตา ทันสมัย และไม่กลืนกับแอปอื่น

### 7.2 Universal Visual Metaphor (สัญลักษณ์สากลที่มองออกใน 0.5 วินาที)
- พื้นที่วาดมีเพียงประมาณ 10x8 พิกเซล **ห้ามวาดรูปนามธรรมที่ต้องตีความ**
- ถ่ายทอดด้วยองค์ประกอบเด่นของสิ่งนั้น:
  - **ข่าวสาร (News)**: แผ่นหนังสือพิมพ์สีขาวขอบคมกริบ + แถบพาดหัวตัวหนา (Headline Banner) + กรอบภาพถ่ายสีฟ้า (Photo Box) + คอลัมน์เนื้อหา 2 ฝั่ง
  - **ภารกิจ (Quests)**: ม้วนคัมภีร์สีทองพร้อมดาวเกียรติยศ
  - **คลินิก/ยา (Effects)**: กากบาทพยาบาลสีขาวบนการ์ดแดง
  - **แอปสโตร์ (App Store)**: ถุงช้อปปิ้งพร้อมหูหิ้วและตราสัญลักษณ์

### 7.3 Contrast Hierarchy & 3D Depth (ลำดับชั้นคอนทราสต์และความลึก)
- **High Contrast Edge**: ขอบนอกของสัญลักษณ์ต้องสว่างคมชัด ตัดกับสีการ์ดชัดเจน (เช่น กระดาษขาว `#ffffff` บนการ์ดแดง `#e11d48`)
- **Internal Layering**: รายละเอียดด้านในใช้น้ำหนักสีต่างกันเพื่อสร้างมิติ (หมึกสีเข้ม `#334155` + กรอบภาพสีฟ้า `#0284c7`)
- **Under-Shadow 3D (Index 5)**: แถบเงาใต้สัญลักษณ์ช่วยผลักวัตถุให้ลอยนูนขึ้นมาจากการ์ด ทำให้ไอคอนดูมีมิติ ไม่แบนเรียบ

### 7.4 Visual Simulation (ตรวจเช็กภาพจำลองก่อนนำไปใช้งาน)
- ใช้การพิมพ์ Emoji Grid หรือ ANSI TrueColor Blocks ใน Terminal เพื่อดูภาพรวมความสมดุลและความชัดเจนของไอคอนในระยะสายตาจริงก่อนคอมมิตเสมอ
